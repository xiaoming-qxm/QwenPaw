QwenPaw 架构文档

本文档站点为 QwenPaw 新开发者提供系统架构的深度理解，特别关注与 AgentScope 1.x 的交互边界，为后续 AgentScope 2.0 重构提供参考。

阅读顺序

推荐路径（渐进式）：

  1. 系统总览 — 建立整体心智模型，理解分层架构和数据流
  2. 核心 Agent 循环 — 深入 ReAct 循环、Mixin 拦截链、Memory/Context
  3. Tools / MCP / Skills — 工具定义、MCP 协议集成、Skill 引导机制及三者关系
  4. 应用层 — FastAPI 服务、Channel 抽象、多 Agent 管理
  5. Provider 与模型层 — LLM 提供商适配、模型工厂、重试与限速
  6. 安全与插件 — ToolGuard、审批流、插件加载机制
  7. AgentScope 边界 — 核心重点：精确 API 映射和完整调用链
  8. 迁移建议 — AgentScope 2.0 迁移策略和风险评估

技术概要

属性值
版本v1.1.9b1
Python3.10 ~ 3.13
核心依赖agentscope==1.0.20, agentscope-runtime==1.1.6
Web 框架FastAPI + Uvicorn
前端React + TypeScript + Vite + Ant Design
Agent 范式ReAct (Reasoning + Acting)
入口命令qwenpaw app (端口 8088)

仓库结构速查

src/qwenpaw/
├── agents/          # Agent 核心：ReAct 循环、工具、Skill、Memory
├── app/             # FastAPI 应用：Channel、Runner、Router、Workspace
├── providers/       # LLM Provider 适配层
├── config/          # Pydantic 配置模型
├── plugins/         # 插件系统
├── security/        # 安全：ToolGuard、SkillScanner
├── cli/             # CLI 命令入口
├── local_models/    # 本地模型管理
└── utils/           # 公共工具

console/             # 前端 React 应用
plugins/             # 用户插件目录
deploy/              # Docker 部署配置
